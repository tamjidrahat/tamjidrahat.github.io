About

I am an Applied Scientist at Amazon Web Services (AWS), working at the frontier of agentic AI for security. I focus on building LLM-agent systems that autonomously detect and repair software vulnerabilities, pushing automated program repair (APR) from research prototypes to production-scale, high-fidelity remediation.

Previously, I built automated solutions for identifying logical flaws in security protocols. My research on single sign-on (OAuth and OpenID Connect) uncovered high-severity vulnerabilities in widely deployed software, including Google's authentication, contributing to 8+ CVEs.

Research Interests

My research lies at the intersection of agentic AI and software security.

  • Agentic AI for Security
  • Automated Program Repair (APR)
  • LLM Agents for Vulnerability Detection & Remediation
  • Agent Evaluation: Validators & LLM-as-a-Judge
  • Retrieval-Augmented Generation for Code
  • Human-in-the-Loop Agent Improvement
  • Security Protocol Analysis & Formal Methods
